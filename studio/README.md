# Deferred content editor

This separate Sanity Studio source is retained for future development.
It is not installed or built by the website or Netlify root build.
Updates is deferred under Option B; no editor service or account setup is asserted.

For a separately authorized future setup, install Studio dependencies in this directory,
copy `.env.example` to `.env`, and supply the intended project ID and dataset.
Never commit credentials. Review schema validation, access permissions, publication guards,
website indexing and end-to-end behavior before enabling publishing.
